# Hyojeong Park — CV website

Static CV website for `https://hjparkolivia.github.io/`.

## Publish on GitHub Pages

1. Put these files at the root of the `hjparkolivia/hjparkolivia.github.io` repository on its `main` branch.
2. In the repository's **Settings → Pages**, select **Deploy from a branch**, then choose `main` and `/ (root)`.
3. After GitHub finishes publishing, open `https://hjparkolivia.github.io/`.

The page uses HTML and CSS only; there is no build step. Edit `index.html` to update CV details and `styles.css` to change the design.

The public page intentionally leaves out the phone number from the source CV. It also does not upload the original PDF.
